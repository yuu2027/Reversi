# オセロゲーム開発仕様書

## 1. プロジェクト概要
## 1.1 開発目的
unityを使用したオセロゲームの開発。通常のオセロのルールに加え、オンライン対戦、難易度別AI対戦、対局履歴の保存・閲覧機能を実装する。

## 1.2 作るもの
- 難易度別オセロAI
- オンライン対戦
- 対局履歴の保存・閲覧機能

## 1.3 開発技術
| 項目 | 使用技術 |
|---|---|
| ゲームエンジン | Unity 6000.4.3f1 |
| プログラミング言語 | C# |
| 開発IDE | Vitual Studio |
| バージョン管理 | Git / GitHub |
| オンライン通信 | 未定 |
| データ保存 | 未定 |
| 対象プラットフォーム | Windows PC |
